
Documentación para hacer deploy

	La aplicación que entrego la trabajé en el dominio local: http://developer-marvel-covalto.local. Deberán cambiar este dominio por aqué en donde vayan a probar la aplicación en su porpio ambiente.


	1. Requisitos mínimos
		php 8.2
		mariadb 10.11.5
		La base de datos tendrá el collation: utf8mb4_general_ci

	2. Ajustar las constantes y variables en los siguientes archivos, de acuerdo a su ambiente:
		1. /.env
			En este archivo sólo hay que cambiar el dominio en la variable: app.baseURL
		1. /app/Config/App.php
			En este archivo sólo hay que cambiar el dominio en la variable: $baseURL
		1. /app/Config/Database.php
		2. /app/Controllers/Datatables/Datatables.php
		3. /app/Config/Constants.php
			En la parte de hasta abajo de este archivo hay múltiples constantes custom que hay que cambiar de acuerdo a su ambiente.

	3. Base de datos
		1. Ejecutar migraciones desde la consola
			cd /raiz/del/proyecto/
			php spark migrate
			php spark db:seed Init

		2. Si por alguna razón no funcionan las migraciones, entonces ejecutar el script db.sql (que está en la raíz del proyecto) en su cliente de base datos preferido.

	4. Crear link simbólico

		Windows
			mklink /D "C:/laragon/www/developer-marvel/public/uploads" "C:/laragon/www/developer-marvel/writable/uploads"

		Linux
			cd /var/www/html/developer-marvel/public
			ln -s /var/www/html/developer-marvel/writable/uploads/ uploads

	5. https://www.tiny.cloud/
		El campo descripción de cada héroe usa TinyMCE, por tanto, para que funcione correctamente el aplicativo es necesario realizar lo siguiente:

		1. Generar api key y poner el <scrip> generado en tiny.cloud, dentro de /app/Views/back/layout/head.php
		2. Agregar el dominio en el que se vaya a montar el presente aplicativo, a los dominios aprovados dentro de tiny.cloud
